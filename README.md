# 建材マートサイト（見積もり専用・Jekyll）

ECサイトではなく、「商品を見て・選んで・まとめて見積もり依頼する」ための
建材マートサイトです。GitHub Pages でそのまま公開できる Jekyll プロジェクトです。

## 現在のスコープ（フェーズ1）

- [x] トップページ（`index.html`）
- [x] 商品一覧ページ（`products/index.html`）— カテゴリー絞り込み・キーワード検索
- [x] 見積もりリストページ（`quote/index.html`）— 選択商品の確認・依頼フォーム
- [ ] 商品詳細ページ（`/products/<商品ID>/`）— **次フェーズで作成予定**

商品一覧ページの各カードは、詳細ページ公開後にリンク先を差し替える想定で、
現時点ではリンクなしのカード表示になっています。

## ディレクトリ構成

```
site/
├── _config.yml            # サイト名・会社情報・カテゴリー定義
├── Gemfile
├── index.html              # トップページ
├── products/index.html     # 商品一覧（絞り込み・検索）
├── quote/index.html        # 見積もりリスト・依頼フォーム
├── _layouts/default.html   # 共通レイアウト
├── _includes/
│   ├── header.html
│   ├── footer.html
│   └── product-plate.html  # 商品カード（トップ・一覧で共用）
├── _data/products.csv      # 商品データ本体（516点）
└── assets/
    ├── css/main.css
    └── js/main.js           # 見積もりリスト・検索・絞り込みのロジック
```

## ローカルで確認する

Ruby と Bundler が必要です。

```bash
bundle install
bundle exec jekyll serve
```

`http://localhost:4000` で確認できます。

## GitHub Pages への公開

1. このフォルダの中身をリポジトリのルートに配置して push します。
2. リポジトリの **Settings → Pages** で、公開元をこのリポジトリ／ブランチに設定します。
   （`Gemfile` の `github-pages` gem を使っているため、GitHub Pages 標準のビルド環境でそのまま動きます）
3. 独自ドメインを使う場合は `CNAME` ファイルを追加してください。

## 商品データの更新方法

`_data/products.csv` が唯一のデータソースです。トップページ・商品一覧の
カテゴリー数や商品カードはすべてこのCSVから自動生成されます。

元のExcel（`商品データclaude指示用.xlsx`）から再生成する場合は、以下の列構成で
CSVを作り直してください（列名は固定）。

| 列名 | 内容 |
|---|---|
| id | 商品ID（一意） |
| major | 大カテゴリー |
| minor | 小カテゴリー |
| model | 型番 |
| name | 商品名 |
| image | 商品画像URL |
| price | 販売価格（数値） |
| price_fmt | 販売価格（カンマ区切り文字列。例: `340,500`） |
| blurb | 簡単な説明文（商品説明の先頭を要約したもの） |

大カテゴリーを追加・変更した場合は `_config.yml` の `categories_order` も
あわせて更新してください（`name` が CSV の `major` と完全一致している必要があります）。

## 見積もりリストの仕組み（現状の実装）

- 「見積もりに追加」ボタンで選択した商品は、ブラウザの `localStorage` に保存されます
  （サーバー・データベースは使っていません＝端末・ブラウザごとに保存されます）。
- `/quote/` ページで数量調整・削除ができ、参考合計が自動計算されます。
- フォーム送信時は、入力内容と選択商品をまとめたメール下書き（`mailto:`）を
  開く簡易的な仕組みになっています。

### 本番運用前に対応をおすすめする点

1. **見積もり依頼の送信方法**：`mailto:` は文字数制限や、メールソフトが
   設定されていない端末では動作しない場合があります。Googleフォームや
   フォーム送信サービス（例：Formspree など）、または自社サーバーでの
   受信処理に置き換えることを推奨します。
2. **商品画像**：Cloudinaryへ移行済みです。`_data/products.csv` の `image` 列は
   `https://res.cloudinary.com/...` を参照しており、移行前の旧ショップ
   （`img21.shop-pro.jp`）URLは `image_original` 列にバックアップとして
   残しています。再アップロード時は `scripts/migrate_images_to_cloudinary.py`
   を利用してください。
3. **価格表示**：掲載価格は「参考価格」として表示しています。実際の見積もり
   金額と乖離がある場合は、価格非表示にする・注記を強めるなどの調整が可能です。
